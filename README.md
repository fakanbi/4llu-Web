# 4llu Website

A commission and portfolio website built for **4llu** (ft. 4LLU), a content creator, artist, ENVTuber, aspiring director, and production manager. This platform serves as a centralized hub where fans and clients can learn about 4llu, view available services, and commission artwork directly.

---

## Overview

The website features a vibrant, personality-driven design that reflects 4llu's creative brand. It was developed in collaboration with 4llu to provide a professional yet playful online presence that consolidates all relevant information in one accessible location.

---

## Key Sections

- **About Me** – Introduces 4llu's background, creative work, and affiliations with productions like Soulstice SMP, Sonder SMP, and Sonare.

- **Commissions** – Displays available commission tiers (Emotes, Headshots, Half Body, Full Body, Reference Sheets) with pricing and service details in an interactive Swiper carousel.

- **Contact** – Footer section with copyright and brand attribution.

---

## Technical Features

- **Responsive Design** – Built with Bootstrap 5.3 and custom CSS to ensure seamless viewing across desktop, tablet, and mobile devices.

- **Interactive Commission Carousel** – Implemented with Swiper.js for smooth navigation through service tiers.

- **Custom Branding** – Hand-drawn style navbar graphics and cloud-themed visual elements that reinforce 4llu's artistic identity.

- **Google Fonts Integration** – Custom typography using "Gochi Hand" and "Coustard" for a distinctive, handcrafted feel.
